# Module 4 · Semaine 21 — Mantra sadhana complète et prana pratishtha

**Leçons sources : L27 (A Full Yoga Mantra Program), L26 (Prana Pratishtha Instruction), + fin de L25 (la sadhana complète)**

## Objectifs d'apprentissage

1. **Construire** une mantra sadhana complète : sankalpa → déité → bija + Gayatri + mantra
   complet → yantra ;
2. **Calculer** le volume d'un anushthana (répétitions, malas, durée) ;
3. **Exécuter** la prana pratishtha : animer un support (statue, yantra) par le prana ;
4. **Lancer** un anushthana personnel.

## Prérequis

Semaine 20.

## Théorie

### La mantra sadhana complète (anushthana)

1. **Formuler le sankalpa** — votre raison, votre intention, ce que vous espérez accomplir.
2. **Discerner la déité tantrique** qui peut vous y aider : pour la richesse, Lakshmi ou
   Kubera ; pour lever les obstacles, Ganesha ; pour la réalisation de soi, Shiva. *(Exemple
   du cours : Shiva, pour l'illumination.)*
3. **Réunir les trois formes** pour cette déité :
   - le **bija mantra** (pour Shiva : *Aum* ; Ganesha : *Gam* ; Lakshmi : *Shreem*…) ;
   - le **Gayatri mantra** de la déité (24 syllabes ; pour Shiva : *Om Tatpurushaya Vidmahe
     Mahadevaya Dhimahi Tanno Rudrah Prachodayat*) [À VÉRIFIER : passage très déformé dans
     la transcription — forme traditionnelle rétablie] ;
   - le **mantra complet** (pour Shiva : *Om Namah Shivaya*).
4. **Dessiner le yantra** — idéalement à la main ; au centre, inscrire le bija mantra.
5. **Gayatri 11 fois** avant de commencer l'anushthana proprement dit, puis le mantra
   complet.

### Calculer l'anushthana

Un **mala** compte 108 grains. Exemple : pour chanter *Om Namah Shivaya* **100 000 fois sur
40 jours**, il faut **27 malas par jour** (27 × 108 × 40 ≈ 116 640). On choisit sa cible
selon le temps disponible.

### La prana pratishtha : animer un support

*Prana pratishtha* signifie « installer le prana » : activer tout objet destiné à être le
catalyseur du divin dans votre culte — la statue de votre *ishta devata*, ou le yantra sur
votre autel.

1. Il faut connaître le **bija** de la déité (ex. : *Aum* pour Shiva).
2. **Inspiration ujjayi** en focalisant le bija dans **chidakasha** (l'espace mental).
3. **Expiration par la narine droite** — pourquoi la droite ? Parce que le prana coule
   naturellement par la narine droite / pingala (le conduit de prana shakti) : on veut du
   prana, donc la droite — en visualisant le bija s'écouler avec le souffle et **se
   déposer au centre (bindu) du yantra**, sur la forme écrite du bija.
4. **Un seul souffle suffit.** L'objet est animé, il « a du prana » : les pujas et
   cérémonies y porteront bien plus de fruit, avec une énergie et une présence palpables.
5. **Pour désactiver** (retirer le prana), on fait l'inverse : inspiration, le bija revient
   du yantra par la narine droite.

## Session LIVE (85 min)

| Durée | Séquence |
|-------|----------|
| 5 min | Accueil |
| 20 min | Théorie : la sadhana complète ; le calcul de l'anushthana ; la prana pratishtha |
| 20 min | **Atelier** : chacun construit son programme (sankalpa → déité → bija/gayatri/mantra) et dessine son yantra |
| 20 min | Pratique : prana pratishtha sur son yantra (un souffle) + japa |
| 15 min | **Binôme** : présenter son programme à l'autre (déité, mantras, volume quotidien) ; retours |
| 5 min | Consignes |

## Pratique SOLO de la semaine (20 min/jour)

- **Lancement de l'anushthana** : Gayatri 11× puis le mantra complet, volume quotidien
  choisi (avec mala) ; durée fixée (par exemple jusqu'à la fin du module) ;
- **Journal** : nombre de malas tenus ; effets ressentis dans la durée.

## Pratique BINÔME de la semaine

- Un échange : chacun présente son programme complet à l'autre et s'engage sur un volume
  quotidien réaliste ; point d'étape à mi-semaine pour se soutenir.

## Session REPLAY

- Prana pratishtha + japa, chaque jour au début de la pratique.

## Précautions

- Choisir un volume **tenable** (mieux vaut peu et régulier que beaucoup et abandonné) ;
- s'en tenir à un mantra libre (bija/Gayatri) ;
- [À VÉRIFIER AVEC L'ENSEIGNANT] la forme exacte du Gayatri de Shiva (transcription
  source déformée).
