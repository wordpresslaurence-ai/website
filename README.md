# Home Harmony — homeharmony.be

Site vitrine statique pour Home Harmony (harmonisation de l'habitat, Belgique).

## Contenu

- `index.html` — page unique avec les sections : accueil, à propos, services, déroulement, témoignages, contact
- `css/style.css` — feuille de style

Aucune dépendance, aucun outil de build : il suffit d'ouvrir `index.html` dans un navigateur ou de déposer les fichiers chez n'importe quel hébergeur.

## À personnaliser

- L'adresse e-mail de contact (`contact@homeharmony.be`) dans la section Contact — à remplacer par la vôtre si différente.
- Les témoignages (textes d'exemple à remplacer par de vrais retours clients).
- Le formulaire de contact utilise un simple lien `mailto:` ; pour un vrai envoi, brancher un service comme Formspree ou le formulaire de votre hébergeur.
